### Enable globals in vitest.config.js

Source: https://github.com/vitest-dev/vitest/blob/v4.1.12/docs/guide/learn/writing-tests.md

Set the `globals` option to `true` in the Vitest config to use `test`, `expect`, `describe`, and other functions without importing them. TypeScript users should also add `"types": ["vitest/globals"]` to `compilerOptions` in `tsconfig.json`.

```javascript
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    globals: true,
  },
})
```

### Configure setupFiles in vitest.config.js

Source: https://github.com/vitest-dev/vitest/blob/v4.1.12/docs/guide/learn/setup-teardown.md

Point the `setupFiles` option at a setup file so its code runs before every test file. Setup files run in a separate phase before the test file is collected, unlike `beforeAll`.

```javascript
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    setupFiles: ['./test/setup.js'],
  },
})
```

```javascript
// This runs before every test file
import { expect } from 'vitest'
import { customMatchers } from './custom-matchers.js'

expect.extend(customMatchers)
```

### Enable global APIs in Vitest configuration

Source: https://github.com/vitest-dev/vitest/blob/v4.1.12/docs/config/globals.md

Enables global test APIs so imports like describe, it, and expect are globally available. Set this when migrating from Jest or using libraries like @testing-library/react that require globals for automatic cleanup.

```js
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    globals: true,
  },
})
```

### Set the test environment option in vitest.config.ts

Source: https://github.com/vitest-dev/vitest/blob/v4.1.12/docs/guide/features.md

After installing happy-dom or jsdom, set test.environment in the config file. Accepted values include 'happy-dom', 'jsdom', and 'node'.

```ts
import { defineConfig } from 'vitest/config'

export default defineConfig({
  test: {
    environment: 'happy-dom', // or 'jsdom', 'node'
  },
})
```
