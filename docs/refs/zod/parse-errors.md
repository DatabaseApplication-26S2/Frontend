### z.treeifyError(error)

Source: https://github.com/colinhacks/zod/blob/v4.6.7/packages/docs/content/error-formatting.mdx

Converts a ZodError into a nested tree structure mirroring the schema layout. It organizes errors under an `errors` array alongside `properties` and `items` for deeper traversal.

```APIDOC
## z.treeifyError(error)

### Description
Converts a ZodError into a nested object structure that mirrors the validated schema hierarchy.

### Signature
`z.treeifyError(error: ZodError): TreeifiedError`

### Parameters
- **error** (`ZodError`) - The error instance produced during validation.

### Returns
A nested object containing:
- **errors** (`string[]`) - Error messages occurring at the current level.
- **properties** (`Record<string, TreeifiedError>`) - Nested errors mapped by object keys.
- **items** (`Array<TreeifiedError | undefined>`) - Nested errors mapped by array indices.

### Example
```ts
const tree = z.treeifyError(result.error);

// Accessing nested errors
tree.properties?.username?.errors;
// => ["Invalid input: expected string, received number"]

tree.properties?.favoriteNumbers?.items?.[1]?.errors;
// => ["Invalid input: expected number, received string"]
```
```

### z.flattenError(error)

Source: https://github.com/colinhacks/zod/blob/v4.6.7/packages/docs/content/error-formatting.mdx

Flattens a ZodError into a shallow error object with `formErrors` and `fieldErrors`. Best suited for flat object schemas and form validation.

```APIDOC
## z.flattenError(error)

### Description
Flattens validation issues into a shallow error object separating top-level schema errors from individual field errors.

### Signature
`z.flattenError(error: ZodError): { formErrors: string[]; fieldErrors: Record<string, string[]> }`

### Parameters
- **error** (`ZodError`) - The error instance to flatten.

### Returns
- **formErrors** (`string[]`) - Array of top-level schema errors (where `path` is empty `[]`).
- **fieldErrors** (`Record<string, string[]>`) - Mapping of field names to arrays of error messages for that field.

### Example
```ts
const flattened = z.flattenError(result.error);

flattened.formErrors;
// => [ 'Unrecognized key: "extraKey"' ]

flattened.fieldErrors.username;
// => [ 'Invalid input: expected string, received number' ]
```
```

### Convert error into a nested object using z.treeifyError()

      errors: [],

### Infer a static type from a Zod schema with z.infer

Source: https://github.com/colinhacks/zod/blob/v4.6.7/packages/docs/content/basics.mdx

Use z.infer<typeof Schema> to extract the inferred TypeScript type from a schema definition and annotate values with it.

```ts
const Player = z.object({ 
  username: z.string(),
  xp: z.number()
});

// extract the inferred type
type Player = z.infer<typeof Player>;

// use it in your code
const player: Player = { username: "billie", xp: 100 };
```
