### schema.refine(check, options?)

Source: https://github.com/colinhacks/zod/blob/v4.6.7/packages/docs/content/api.mdx

Applies a custom validation rule to a Zod schema. Refinement functions return a falsy value to indicate validation failure and should never throw errors.

```APIDOC
## schema.refine(check, options?)

### Description
Performs custom validation checks on a schema when native validation APIs are not sufficient. Refinement functions must return a falsy value on failure and truthy on success.

### Method Signature
`schema.refine(check: (val: T) => boolean, options?: RefineOptions): ZodSchema`
`z.refine(check: (val: T) => boolean, options?: RefineOptions): ZodCheck`

### Parameters
- **check** `(val: T) => boolean` - Required. A validation function receiving the parsed value. Returning a falsy value signals validation failure.
- **options** `object` - Optional configuration object:
  - **error** `string | ((iss: { input: any }) => string)` - Custom error message or function returning an error string based on the issue object.
  - **abort** `boolean` - If `true`, stops executing subsequent validation checks when this refinement fails.

### Usage Example

```ts
import { z } from "zod";

// Basic refinement
const myString = z.string().refine((val) => val.length <= 255);

// Custom error message
const withCustomError = z.string().refine((val) => val.length > 8, {
  error: "Too short!"
});

// Dynamic error message based on issue input
const withDynamicError = z.string().refine((val) => val.length > 8, {
  error: (iss) => `Too short: "${iss.input}"`
});

// Abort validation on failure
const withAbort = z.string()
  .refine((val) => val.length > 8, { error: "Too short!", abort: true })
  .refine((val) => val === val.toLowerCase(), { error: "Must be lowercase", abort: true });
```
```

### Customize refinement error messages with error option

Source: https://github.com/colinhacks/zod/blob/v4.6.7/packages/docs/content/api.mdx

Pass a custom string to the error option in a refinement to define the error message returned on validation failure.

```ts
const myString = z.string().refine((val) => val.length > 8, { 
  error: "Too short!" 
});
```

```ts
const myString = z.string().check(
  z.refine((val) => val.length > 8, { error: "Too short!" })
);
```

### Create dynamic refinement error messages with issue context

Source: https://github.com/colinhacks/zod/blob/v4.6.7/packages/docs/content/api.mdx

Supply a function to the error option that receives the issue object to generate dynamic error messages using the input value.

```ts
const myString = z.string().refine((val) => val.length > 8, {
  error: (iss) => `Too short: "${iss.input}"`
});

myString.parse("OH NO"); // ❌ Too short: "OH NO"
```

```ts
const myString = z.string().check(
  z.refine((val) => val.length > 8, { error: (iss) => `Too short: "${iss.input}"` })
);

z.parse(myString, "OH NO"); // ❌ Too short: "OH NO"
```
