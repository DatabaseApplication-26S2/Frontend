### Adjust stroke width with strokeWidth prop

Source: https://github.com/lucide-icons/lucide/blob/1.49.0/docs/guide/react/basics/stroke-width.md

Use the `strokeWidth` prop to set a custom stroke width on a Lucide React icon. The example sets `strokeWidth={1}` on a `FolderLock` icon to make the strokes thinner than the default `2px`.

```jsx
import { FolderLock } from "lucide-react";

function App() {
  return (
    <div className="app">
      <FolderLock strokeWidth={1} />
    </div>
  );
}

export default App;
```
