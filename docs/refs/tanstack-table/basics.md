### Client-Side Pagination Row Model Setup

Source: https://github.com/tanstack/table/blob/v8.20.5/docs/guide/pagination.md

Import and configure the pagination row model for client-side pagination in TanStack Table. Pass getPaginationRowModel() to the useReactTable hook to enable built-in pagination logic.

```jsx
import { useReactTable, getCoreRowModel, getPaginationRowModel } from '@tanstack/react-table';
//...
const table = useReactTable({
  columns,
  data,
  getCoreRowModel: getCoreRowModel(),
  getPaginationRowModel: getPaginationRowModel(), //load client-side pagination code
});
```

### Migrate useTable to useReactTable with row models

Source: https://github.com/tanstack/table/blob/v8.20.5/docs/guide/migrating.md

Migrate from the old useTable hook with plugin hooks to the new useReactTable hook with row model options. The old plugin system is replaced by tree-shakable row model imports. The order of row models no longer matters, unlike the old hook order.

```tsx
- import { useTable, usePagination, useSortBy } from 'react-table'; // [!code --]
+ import { // [!code ++]
+   useReactTable, // [!code ++]
+   getCoreRowModel, // [!code ++]
+   getPaginationRowModel, // [!code ++]
+   getSortedRowModel // [!code ++]
+ } from '@tanstack/react-table'; // [!code ++]

// ...

-   const tableInstance = useTable( // [!code --]
-     { columns,  data }, // [!code --]
-     useSortBy, // [!code --]
-     usePagination, //order of hooks used to matter // [!code --]
-     // etc. // [!code --]
-   ); // [!code --]
+   const tableInstance = useReactTable({ // [!code ++]
+     columns, // [!code ++]
+     data, // [!code ++]
+     getCoreRowModel: getCoreRowModel(), // [!code ++]
+     getPaginationRowModel: getPaginationRowModel(), // [!code ++]
+     getSortedRowModel: getSortedRowModel(), //order doesn't matter anymore! // [!code ++]
+     // etc. // [!code ++]
+   }); // [!code ++]
```

### Client-side sorting with getSortedRowModel

Source: https://github.com/tanstack/table/blob/v8.20.5/docs/guide/sorting.md

Enables client-side sorting by providing the getSortedRowModel function as the sorting row model. This transforms rows into sorted rows based on the current sorting state.

```jsx
import { useReactTable } from '@tanstack/react-table'
//...
const table = useReactTable({
  columns,
  data,
  getCoreRowModel: getCoreRowModel(),
  getSortedRowModel: getSortedRowModel(), //provide a sorting row model
})
```

### Sorting Guide > Client-Side Sorting

Source: https://github.com/tanstack/table/blob/v8.20.5/docs/guide/sorting.md

To implement client-side sorting, first you have to provide a sorting row model to the table. You can import the `getSortedRowModel` function from TanStack Table, and it will be used to transform your rows into sorted rows.

```jsx
import { useReactTable } from '@tanstack/react-table'
//...
const table = useReactTable({
  columns,
  data,
  getCoreRowModel: getCoreRowModel(),
  getSortedRowModel: getSortedRowModel(), //provide a sorting row model
})

### getFilteredRowModel (Table Option)

Source: https://github.com/tanstack/table/blob/v8.20.5/docs/api/features/global-filtering.md

Provides a custom function to calculate the filtered row model.

```APIDOC
## getFilteredRowModel

### Description
If provided, this function is called **once** per table and should return a **new function** which will calculate and return the row model for the table when it's filtered.

- For server-side filtering, this function is unnecessary and can be ignored since the server should already return the filtered row model.
- For client-side filtering, this function is required. A default implementation is provided via any table adapter's `{ getFilteredRowModel }` export.

### Type
`(table: Table<TData>) => () => RowModel<TData>` (optional)

### Example
```tsx
import { getFilteredRowModel } from '@tanstack/[adapter]-table'

getFilteredRowModel: getFilteredRowModel(),
```
