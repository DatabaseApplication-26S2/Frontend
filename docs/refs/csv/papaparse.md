### Parse CSV string, unparse, parse file, and stream with worker

Source: https://github.com/mholt/papaparse/blob/master/docs/index.html

Shows the core Papa Parse API: parse a CSV string, convert data back to CSV, parse a local file with a complete callback, and stream a large file in a worker thread with a step callback.

```javascript
// Parse CSV string
var data = Papa.parse(csv);

// Convert back to CSV
var csv = Papa.unparse(data);

// Parse local CSV file
Papa.parse(file, {
	complete: function(results) {
		console.log("Finished:", results.data);
	}
});

// Stream big file in worker thread
Papa.parse(bigFile, {
	worker: true,
	step: function(results) {
		console.log("Row:", results.data);
	}
});
```

### Behavior Notes

Source: https://github.com/mholt/papaparse/blob/master/_autodocs/api-reference/parse.md

- **Worker mode** — with `worker: true` on a `Papa.WORKERS_SUPPORTED` environment, parsing is offloaded to a `Blob`-backed `Worker`; `step`/`chunk`/`complete`/`error` callbacks are re-wired across threads. `pause`/`resume` on the worker-side handle throw `Error('Not implemented.')`.

### StepResult object structure

Source: https://github.com/mholt/papaparse/blob/master/_autodocs/types.md

Shape of the object passed to a `step` callback for each row. `data` is a single row (array of strings or object when `header: true`), not an array of rows like in `ParseResult`. The `step` callback also receives the live `ParserHandle` as a second argument.

```javascript
{
	data: Row,      // a single row: array of strings, or object when header: true
	errors: ParseErrorEntry[],
	meta: ParseMeta
}
```

### Examples > Streaming a file with pause/resume and error handling

Source: https://github.com/mholt/papaparse/blob/master/_autodocs/api-reference/parse.md

```js
import Papa from 'papaparse';

Papa.parse(fileInput, {           // fileInput: a <input type="file"> File object
	header: true,
	chunkSize: 1024 * 1024,       // 1 MB chunks
	step: function(results, parser) {
		console.log('row:', results.data);
		parser.pause();
		// ... do work ...
		parser.resume();
	},
	complete: function(results) {
		console.log('done, rows:', results.data.length);
	},
	error: function(err) {
		console.error('parse failed:', err.message);
	}
});
```

### Parse a file in a worker thread

Source: https://github.com/mholt/papaparse/blob/master/docs/index.html

Set worker: true to run parsing in a Web Worker, keeping the page responsive. May take slightly longer but avoids UI lockup.

```javascript
Papa.parse(bigFile, {
	worker: true,
	step: function(row) {
		console.log("Row:", row.data);
	},
	complete: function() {
		console.log("All done!");
	}
});
```
