### Papa.unparse(data[, config])

Source: https://github.com/mholt/papaparse/blob/master/docs/docs.html

Converts an array of arrays or an array of objects into a delimited text string. Returns the resulting CSV string.

```APIDOC
## Papa.unparse(data[, config])

### Description
Converts an array of arrays or an array of objects into a delimited text string. Returns the resulting CSV string.

### Method
unparse

### Endpoint
Papa.unparse(data[, config])

### Parameters
#### data
- **data** (Array|Object) - Required - Can be an array of arrays, an array of objects, or an object with `fields` and `data` properties.

#### config (optional)
- **quotes** (boolean|Array|Function) - Optional - If true, forces all fields to be enclosed in quotes. If an array of booleans, specifies which fields to force-quote. A function can determine quotes value per cell.
- **quoteChar** (string) - Optional - The character used to quote fields. Default: `'"'`.
- **escapeChar** (string) - Optional - The character used to escape `quoteChar` inside field values. Default: `'"'`.
- **delimiter** (string) - Optional - The delimiting character. Default: `','`.
- **header** (boolean) - Optional - If false, omits the header row. Default: `true`.
- **newline** (string) - Optional - The newline sequence. Default: `"\r\n"`.
- **skipEmptyLines** (boolean|string) - Optional - If true, skips completely empty lines. If 'greedy', skips lines with only whitespace. Default: `false`.
- **columns** (Array|null) - Optional - Manually specify keys for array of objects. Default: `null`.
- **escapeFormulae** (boolean|RegExp) - Optional - If true, prepends `'` to fields starting with `=`, `+`, `-`, `@`, `\t`, or `\r` to prevent CSV injection. Can be a RegExp to override.

### Request Example
```javascript
// Two-line, comma-delimited file
var csv = Papa.unparse([
	["1-1", "1-2", "1-3"],
	["2-1", "2-2", "2-3"]
]);
```

### Response
Returns the resulting delimited text as a string.

### Response Example
```
"1-1,1-2,1-3\n2-1,2-2,2-3"
```
```

### Papa.unparse(data, config?)

Source: https://github.com/mholt/papaparse/blob/master/_autodocs/api-reference/unparse.md

Documentation for the Papa.unparse function, including parameters, configuration options, and examples.

```APIDOC
## Papa.unparse(data, config?)

### Description
Converts an array of arrays or an array of objects into a CSV string. Accepts a JSON string or a parse result object with `data` and `meta` fields.

### Method
Function call (synchronous)

### Endpoint
`Papa.unparse(data, config?)`

### Parameters
#### data (Array|String|Object) - Required
- Array of arrays: each inner array is a row, first row is the header if `header` is true (default).
- Array of objects: keys become headers, values become cells.
- JSON string: parsed as an array of arrays or objects.
- Object with `data` and `meta` fields: `data` is the array of rows, `meta.fields` provides the column order.

#### config (Object) - Optional
- `columns` (Array) - Optional - Forces the header/key order; missing keys become empty strings. Throws an error if empty array.
- `quotes` (Boolean|Array|Function) - Optional - Controls quoting: `true` quotes all, array of booleans per column, or function `(value, columnIndex) => boolean`.
- `newline` (String) - Optional - Line ending character(s), default `\r\n`.
- `escapeFormulae` (Boolean) - Optional - Prefixes cells starting with `=`, `+`, `-`, `@` with a single quote to prevent formula injection.
- `escapeChar` (String) - Optional - Changes the escaped-quote sequence from `""` to `<escapeChar>"`.
- `delimiter` (String) - Optional - Field delimiter; must not contain `\r`, `\n`, `"`, or BOM, otherwise ignored.

### Request Example
```js
import Papa from 'papaparse';

const csv = Papa.unparse([{ name: 'alice', age: 42 }]);
```

### Response
#### Success Response
Returns a CSV string.

#### Response Example
```
"name,age\r\nalice,42"
```

### Error Handling
- Throws an error if `columns` is an empty array: `'Option columns is empty'`.
- Invalid delimiters are silently ignored (default `,` used).
```

### Basic unparse: arrays and objects

Source: https://github.com/mholt/papaparse/blob/master/_autodocs/api-reference/unparse.md

Shows how to convert an array of arrays or an array of objects to CSV strings using Papa.unparse. The output uses \r\n line endings by default.

```javascript
import Papa from 'papaparse';

const csv1 = Papa.unparse([['A', 'b'], ['c', 'd']]);
// "A,b\r\nc,d"

const csv2 = Papa.unparse([{ name: 'alice', age: 42 }, { name: 'bob', age: 7 }]);
// "name,age\r\nalice,42\r\nbob,7"
```
