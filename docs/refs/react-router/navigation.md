### useNavigate

Source: https://reactrouter.com/7.13.0/api/hooks/useNavigate

Returns a navigate function for programmatic navigation. The function can be called with a path string, a To object, or a number to navigate back/forward in the history stack. Options such as replace and preventScrollReset can be passed.

```APIDOC
## useNavigate

### Description
Returns a navigate function for programmatic navigation. The function can be called with a path string, a To object, or a number to navigate back/forward in the history stack. Options such as replace and preventScrollReset can be passed.

### Signature
```tsx
function useNavigate(): NavigateFunction
```

### Returns
A navigate function for programmatic navigation

### Examples

#### Navigate to another path
```tsx
navigate("/some/route");
navigate("/some/route?search=param");
```

#### Navigate with a To object
All properties are optional.
```tsx
navigate({
  pathname: "/some/route",
  search: "?search=param",
  hash: "#hash",
  state: { some: "state" },
});
```

#### Navigate back or forward in the history stack
```tsx
// back
// often used to close modals
navigate(-1);

// forward
// often used in a multistep wizard workflows
navigate(1);
```

#### Replace the current entry in the history stack
```tsx
navigate("/some/route", { replace: true });
```

#### Prevent Scroll Reset
```tsx
navigate("?some-tab=1", { preventScrollReset: true });
```

#### Return Type Augmentation
```ts
// If using <BrowserRouter>
declare module "react-router" {
  interface NavigateFunction {
    (to: To, options?: NavigateOptions): void;
    (delta: number): void;
  }
}

// If using <RouterProvider> or Framework mode
declare module "react-router" {
  interface NavigateFunction {
    (to: To, options?: NavigateOptions): Promise<void>;
    (delta: number): Promise<void>;
  }
}
```

### Navigate

Source: https://reactrouter.com/7.13.0/api/components/Navigate

A component-based version of useNavigate to use in a React.Component class where hooks cannot be used. It's recommended to avoid using this component in favor of useNavigate.

```APIDOC
## Navigate

### Description
A component-based version of [`useNavigate`](../hooks/useNavigate) to use in a
[`React.Component` class](https://react.dev/reference/react/Component) where
hooks cannot be used.

It's recommended to avoid using this component in favor of [`useNavigate`](../hooks/useNavigate).

### Signature

```tsx
function Navigate({ to, replace, state, relative }: NavigateProps): null
```

### Props

#### to
- **type** (string | Path) - Required - The path to navigate to. This can be a string or a [`Path`](https://api.reactrouter.com/v7/interfaces/react_router.Path.html) object

#### replace
- **type** (boolean) - Optional - Whether to replace the current entry in the [`History`](https://developer.mozilla.org/en-US/docs/Web/API/History) stack

#### state
- **type** (any) - Optional - State to pass to the new [`Location`](https://api.reactrouter.com/v7/interfaces/react_router.Location.html) to store in [`history.state`](https://developer.mozilla.org/en-US/docs/Web/API/History/state).

#### relative
- **type** (RelativeRoutingType) - Optional - How to interpret relative routing in the `to` prop. See [`RelativeRoutingType`](https://api.reactrouter.com/v7/types/react_router.RelativeRoutingType.html).

### Returns
- **null** - This component renders nothing.

### Example

```tsx
<Navigate to="/tasks" />
```
```

### Render child routes with Outlet

Source: https://reactrouter.com/7.13.0/api/components/Outlet

Import Outlet from react-router and place it inside a parent route component to render the matching child route, or nothing if no child matches.

```tsx
import { Outlet } from "react-router";

export default function SomeParent() {
  return (
    <div>
      <h1>Parent Content</h1>
      <Outlet />
    </div>
  );
}
```

### useNavigate hook for programmatic navigation

Source: https://reactrouter.com/7.13.0/start/declarative/navigating

Use `useNavigate` to navigate programmatically, e.g., after a form submission. Reserve it for situations where the user is not interacting; prefer `Link` or `NavLink` for normal navigation.

```tsx
import { useNavigate } from "react-router";

export function LoginPage() {
  let navigate = useNavigate();

  return (
    <>
      <MyHeader />
      <MyLoginForm
        onSuccess={() => {
          navigate("/dashboard");
        }}
      />
      <MyFooter />
    </>
  );
}
```
