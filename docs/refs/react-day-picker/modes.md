### excludeDisabled prop

Source: https://github.com/gpbl/react-day-picker/blob/v10.0.2/apps/website/docs/selections/disabling-dates.mdx

In range mode, the `excludeDisabled` prop excludes disabled dates from the selected range. If a disabled date is selected, the range resets.

```APIDOC
## [PROP] excludeDisabled

### Description
In `range` mode, disabled dates are included in the selected range by default. The `excludeDisabled` prop excludes disabled dates from the range. If a disabled date is selected, the range will reset.

### Method
PROP

### Endpoint
DayPicker.excludeDisabled

### Parameters
#### Prop Value
- **excludeDisabled** (boolean) - Optional - When `true`, disabled dates are excluded from the range selection. Defaults to `false`.

### Request Example
```tsx
<DayPicker
  mode="range"
  // Disable weekends
  disabled={{ dayOfWeek: [0, 6] }}
  // Reset range when a disabled date is included
  excludeDisabled
/>
```

### Response
#### Success Response (200)
- **excludeDisabled** (boolean) - Returns `true` if disabled dates are excluded from the range, `false` otherwise.

#### Response Example
```json
{
  "excludeDisabled": true
}
```
```

### disabled prop

Source: https://github.com/gpbl/react-day-picker/blob/v10.0.2/apps/website/docs/selections/disabling-dates.mdx

The `disabled` prop accepts a Matcher or an array of matchers to specify which dates should be disabled. It can be used in any selection mode.

```APIDOC
## [PROP] disabled

### Description
The `disabled` prop prevents specific dates from being selected in any mode. It accepts a single matcher or an array of matchers.

### Method
PROP

### Endpoint
DayPicker.disabled

### Parameters
#### Prop Value
- **matcher** (Matcher | Matcher[]) - Required - A matcher or array of matchers specifying which dates to disable. Supported matcher types: `boolean`, `Date`, `Date[]`, `DateRange`, `DateBefore`, `DateAfter`, `DateInterval`, `DayOfWeek`, `(date: Date) => boolean`, or `Matcher[]`.

### Request Example
```tsx
// Disable all dates
<DayPicker disabled />

// Disable a specific date
<DayPicker disabled={new Date(2023, 9, 1)} />

// Disable an array of dates
<DayPicker disabled={[new Date(2023, 9, 1), new Date(2023, 9, 2)]} />

// Disable a range of dates
<DayPicker disabled={{ from: new Date(2023, 9, 1), to: new Date(2023, 9, 5) }} />

// Disable specific days of the week
<DayPicker disabled={{ dayOfWeek: [0, 6] }} /> // disable weekends

// Disable dates before a specific date
<DayPicker disabled={{ before: new Date(2023, 9, 1) }} />

// Disable dates after a specific date
<DayPicker disabled={{ after: new Date(2023, 9, 5) }} />

// Disable dates between two dates
<DayPicker disabled={{ before: new Date(2023, 9, 1), after: new Date(2023, 9, 5) }} />
```

### Response
#### Success Response (200)
- **disabled** (boolean) - Returns `true` if the date is disabled, `false` otherwise.

#### Response Example
```json
{
  "disabled": true
}
```
```
