### Setup Worker with HTTP GET Handler

Source: https://github.com/mswjs/msw/blob/v2.15.0/README.md

Imports the MSW browser API and defines a request handler for a GET request to 'https://github.com/octocat'. The handler returns a mocked JSON response with status 202 and status text 'Mocked status'. The worker is started with 'worker.start()' to begin intercepting network requests.

```javascript
// 1. Import the library.
import { http, HttpResponse } from 'msw'
import { setupWorker } from 'msw/browser'

// 2. Describe network behavior with request handlers.
const worker = setupWorker(
  http.get('https://github.com/octocat', ({ request, params, cookies }) => {
    return HttpResponse.json(
      {
        message: 'Mocked response',
      },
      {
        status: 202,
        statusText: 'Mocked status',
      },
    )
  }),
)

// 3. Start mocking by starting the Service Worker.
await worker.start()
```

### Node.js integration test: example.test.ts

Source: https://github.com/mswjs/msw/blob/v2.15.0/CONTRIBUTING.md

Node.js usage example for intercepting GET /books using setupServer, with the usage example kept directly in the test file. Includes beforeAll/afterAll hooks and a test that asserts the mocked response.

```typescript
// test/node/example.test.ts
import { http, HttpResponse } from 'msw'
import { setupServer } from 'msw/node'

const server = setupServer(
  http.get('/books', () => {
    return HttpResponse.json([
      {
        id: 'ea42ffcb-e729-4dd5-bfac-7a5b645cb1da',
        title: 'The Lord of the Rings',
        publishedAt: -486867600,
      },
    ])
  }),
)

beforeAll(() => server.listen())

afterAll(() => server.close())

test('returns a mocked response', async () => {
  const res = await fetch('/books')

  expect(await res.json()).toEqual([
    {
      id: 'ea42ffcb-e729-4dd5-bfac-7a5b645cb1da',
      title: 'The Lord of the Rings',
      publishedAt: -486867600,
    },
  ])
})
```
