### Configure ignore patterns in ESLint

Source: https://github.com/eslint/eslint/blob/v9.39.3/docs/src/use/configure/migration-guide.md

Configure files and directories that ESLint should ignore during linting. Note the difference in glob patterns for flat config, where '**/temp.js' is needed to ignore all files named 'temp.js'.

```javascript
// .eslintrc.js
module.exports = {
	// ...other config
	ignorePatterns: ["temp.js", "config/*"],
};
```

```javascript
import { defineConfig } from "eslint/config";

export default defineConfig([
	// ...other config
	{
		// Note: there should be no other properties in this object
		ignores: ["**/temp.js", "config/*"],
	},
]);
```

### Migration Guide > Ignore Patterns

Source: https://github.com/eslint/eslint/blob/v9.39.3/docs/src/use/configure/migration-guide.md

In flat config, the ignores property replaces ignorePatterns. A pattern like temp.js only ignores files in the same directory as the config file; use **/temp.js to ignore all files with that name. Additionally, dotfiles are no longer ignored by default and require an explicit pattern like **/.* if they should be excluded.

### Load plugin with flat config format

Source: https://github.com/eslint/eslint/blob/v9.39.3/docs/src/use/configure/migration-guide.md

Object-based plugin loading in flat config using import statements and the defineConfig helper. Plugins are imported as JavaScript objects rather than strings.

```javascript
// eslint.config.js

import { defineConfig } from "eslint/config";
import jsdoc from "eslint-plugin-jsdoc";

export default defineConfig([
	{
		files: ["**/*.js"],
		plugins: {
			jsdoc: jsdoc,
		},
		rules: {
			"jsdoc/require-description": "error",
			"jsdoc/check-values": "error",
		},
	},
]);
```

### Ignoring Files

Source: https://github.com/eslint/eslint/blob/v9.39.3/docs/src/use/configure/migration-guide.md

ESLint provides different methods for ignoring files depending on the configuration format used. In the legacy eslintrc system, files are ignored using a separate `.eslintignore` file or the `ignorePatterns` property. In flat config, ignoring files is handled via the `ignores` property within a configuration object that contains no other properties. Note that flat config does not support `.eslintignore` files, requiring patterns to be migrated directly into the configuration.

### Configure file matching and exclusions in ESLint

Source: https://github.com/eslint/eslint/blob/v9.39.3/docs/src/use/configure/configuration-files.md

Use files to include patterns and ignores to exclude specific subdirectories or files. Patterns are evaluated relative to the config file location.

```javascript
// eslint.config.js
import { defineConfig } from "eslint/config";

export default defineConfig([
	// matches all files ending with .js
	{
		files: ["**/*.js"],
		rules: {
			semi: "error",
		},
	},

	// matches all files ending with .js except those in __tests
	{
		files: ["**/*.js"],
		ignores: ["__tests/**"],
		rules: {
			"no-console": "error",
		},
	},
]);
```
