## `type`

### Description
Types text into an element, simulating user input. Supports keyboard descriptors, selection control, and options to skip click or auto-close.

### Signature
```ts
export async function type(
  this: Instance,
  element: Element,
  text: string,
  {
    skipClick = this.config.skipClick,
    skipAutoClose = this.config.skipAutoClose,
    initialSelectionStart,
    initialSelectionEnd,
  }: typeOptions = {},
): Promise<void>
```

### Parameters
- `element` (Element) - Required - Target element
- `text` (string) - Required - Text (may contain keyboard descriptors, see [keyboard.md](keyboard.md))
- `skipClick` (boolean) - Optional - Default: `config.skipClick` (`false`) - Skip the implicit click on the element first
- `skipAutoClose` (boolean) - Optional - Default: `config.skipAutoClose` (`false`) - Skip releasing keys still pressed after typing (i.e. keep `{key>}`-held keys pressed)
- `initialSelectionStart` (number) - Optional - Move the selection caret to this offset before typing
- `initialSelectionEnd` (number) - Optional - Default: `initialSelectionStart` - End offset of the initial selection

### Behavior
Returns immediately for disabled elements; unless `skipClick` performs `this.click(element)`; if `initialSelectionStart` is set, calls `setSelectionRange(element, initialSelectionStart, initialSelectionEnd ?? initialSelectionStart)`; then `this.keyboard(text)`; finally, unless `skipAutoClose`, `releaseAllKeys(this)`.

### Request Example
```ts
const user = userEvent.setup()
await user.type(input, 'Hello, World!', {delay: 1})
await user.type(input, 'X', {initialSelectionStart: 0, initialSelectionEnd: 5})
// selects first 5 chars and replaces them with 'X'
```

### Error handling example
```ts
const user = userEvent.setup()
await user.type(disabledInput, 'abc') // no error, returns early for disabled elements
```
```

### keyboard(text: string): Promise<void>

```APIDOC
## keyboard(text: string): Promise<void>

### Description
Simulates keyboard input. Plain characters are typed, while `{descriptor}` and `[code]` tags trigger key events. Each action is executed with a `delay`/`advanceTimers` pause in between.

### Method
keyboard

### Endpoint
keyboard(text: string): Promise<void>

### Parameters
- **text** (string) - Required - Keyboard input; plain characters are typed, `{descriptor}`/`[code]` tags trigger key events (see grammar below)

### Response
Returns a Promise that resolves when all keyboard actions are completed.

### Request Example
```ts
import {userEvent} from '@testing-library/user-event'

const user = userEvent.setup()
await user.keyboard('hello')            // types each char, fires keydown/keypress/keyup per char
await user.keyboard('{Shift>}A{/Shift}') // hold Shift, type "A", release Shift
await user.keyboard('[ControlLeft>][KeyA][/ControlLeft]') // select-all gesture via physical codes
```

### Error Handling Example
```ts
import {userEvent} from '@testing-library/user-event'

const user = userEvent.setup()
try {
  await user.keyboard('{unknownKey')
} catch (error) {
  // Error: Expected repeat modifier or release modifier or "}" but found "" in "{unknownKey"
  // See https://testing-library.com/docs/user-event/keyboard ...
}
```
```

```APIDOC
## setup() / setupMain

### Description
Creates a new session instance with the given options. It merges options with defaults, prepares the document, installs a clipboard stub, and returns a UserEvent whose methods share state and configuration.

### Signature
```ts
export function setupMain(options: Options = {}) {
```

### Parameters
#### Options
- **options** (Options) - Optional - Configuration options for the session.

### Returns
Returns a `UserEvent` (the API object of a new `Instance`).

### Behavior
1. Merges `options` with `defaultOptionsSetup` and resolves the `document`.
2. Prepares the document with event interceptors/patches (`prepareDocument`, `patchFocus`) unless already prepared.
3. Installs a stub for `navigator.clipboard` on the document's view (`attachClipboardStubToView`) unless already stubbed.
4. Creates a new `System` (shared keyboard + pointer device state) and returns a `UserEvent` whose methods share that state and configuration.

### Request Example
```ts
import {userEvent} from '@testing-library/user-event'

const user = userEvent.setup({delay: 5})

await user.click(screen.getByRole('button'))
await user.type(screen.getByLabelText('Name'), 'Ada')
// second session is fully isolated from the first
const other = userEvent.setup({skipHover: true})
await other.clear(screen.getByLabelText('Name'))
```

### Error handling example
```ts
import {userEvent} from '@testing-library/user-event'

const user = userEvent.setup({pointerEventsCheck: 4})
try {
  await user.click(elementHiddenByPointerEvents)
} catch (error) {
  // Error: "Unable to perform pointer interaction as the element has `pointer-events: none`: ..."
  console.error('pointer interaction rejected', error)
}
```
```
