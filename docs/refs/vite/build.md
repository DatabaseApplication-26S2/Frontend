### Import named exports dynamically using the import option

Source: https://github.com/vitejs/vite/blob/v7.3.5/docs/guide/features.md

Use the import option to load only specific named exports from matching modules dynamically.

```ts twoslash
import 'vite/client'
// ---cut---
const modules = import.meta.glob('./dir/*.js', { import: 'setup' })
```

```ts
// code produced by vite
const modules = {
  './dir/bar.js': () => import('./dir/bar.js').then((m) => m.setup),
  './dir/foo.js': () => import('./dir/foo.js').then((m) => m.setup),
}
```

### preview(inlineConfig)

Source: https://github.com/vitejs/vite/blob/v7.3.5/docs/guide/api-javascript.md

Starts a local server to preview the production build output. Returns a Promise resolving to a PreviewServer instance.

```APIDOC
## `preview`

### Description
Starts a local preview server for verifying production builds.

### Type Signature
```ts
async function preview(inlineConfig?: InlineConfig): Promise<PreviewServer>
```

### Parameters
- **inlineConfig** (`InlineConfig`, optional) - Configuration options for the preview server, including `mode`, `configFile`, and `preview` settings.

### Returns
- `Promise<PreviewServer>` - A promise resolving to the preview server instance.

### Usage Example
```ts
import { preview } from 'vite'

const previewServer = await preview({
  // any valid user config options, plus `mode` and `configFile`
  preview: {
    port: 8080,
    open: true,
  },
})

previewServer.printUrls()
previewServer.bindCLIShortcuts({ print: true })
```
```

### Run vite preview CLI command

Source: https://github.com/vitejs/vite/blob/v7.3.5/docs/guide/cli.md

Starts a local server in the build directory (defaulting to dist) to preview production builds. Run vite build beforehand to ensure output files are up-to-date.

```bash
vite preview [root]
