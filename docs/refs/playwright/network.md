### Page.waitForResponse

Source: https://github.com/microsoft/playwright/blob/v1.64.1/docs/src/network.md

Waits for a matching network response triggered by page actions using a regular expression or a predicate function.

```APIDOC
## Page.waitForResponse

### Description
Waits for a network response matching a specified regular expression pattern or predicate function taking a `Response` object.

### Parameters
- **urlOrPredicate** (`RegExp` | `Function` | `Pattern` | `Regex`) - Required - A regular expression or predicate function matching the expected response URL or response object attributes.

### SDK Examples

#### JavaScript
```js
// Use a RegExp. Note no await.
const responsePromise = page.waitForResponse(/\.jpeg$/);
await page.getByText('Update').click();
const response = await responsePromise;

// Use a predicate taking a Response object. Note no await.
const responsePromise = page.waitForResponse(response => response.url().includes(token));
await page.getByText('Update').click();
const response = await responsePromise;
```

### async method: Page.route

Source: https://github.com/microsoft/playwright/blob/v1.64.1/docs/src/api/class-page.md

Routes network requests made by a page, allowing modification, mocking, or aborting of requests matching a URL pattern. Once routing is enabled, every matching request will stall unless continued, fulfilled, or aborted. Returns a Disposable.

```APIDOC
## async method: Page.route

### Description
Routing provides the capability to modify network requests that are made by a page. Once routing is enabled, every request matching the url pattern will stall unless it's continued, fulfilled or aborted. Returns a Disposable.

### Method
async method

### Parameters
#### Path Parameters
- **url** (string | RegExp | URLPattern | function(URL): boolean) - Required - A glob pattern, regex pattern, URL pattern, or predicate that receives a URL to match during routing. If `Browser.newContext.baseURL` is set in the context options and the provided URL is a string that does not start with `*`, it is resolved using the `new URL()` constructor.

It is possible to examine the request to decide the route action. For example, mocking all requests that contain some post data, and leaving all other requests as is:

```js
await page.route('/api/**', async route => {
  if (route.request().postData().includes('my-string'))
    await route.fulfill({ body: 'mocked-data' });
  else
    await route.continue();
});
```

```java

  else
    route.resume();
});
```

```APIDOC
## Page.waitForResponse

### Description
Waits for a network response matching the given URL string, regex, or predicate. Returns the matched [Response] object. In Python this is an async method returning an `EventContextManager<Response>`; in JavaScript it returns a Promise.

### Method
Page.waitForResponse

### Parameters

#### Path Parameters
None

#### Query Parameters
None

#### Request Body
- **urlOrPredicate** (string | RegExp | function(Response): boolean | Promise<boolean>) - Required - Request URL string, regex or predicate receiving [Response] object. When a `Browser.newContext.baseURL` via the context options was provided and the passed URL is a path, it gets merged via the `new URL()` constructor.
- **timeout** (float) - Optional - Maximum wait time in milliseconds, defaults to 30 seconds, pass `0` to disable the timeout. The default value can be changed by using the `BrowserContext.setDefaultTimeout` or `Page.setDefaultTimeout` methods.
- **signal** - Optional - Wait-for-event signal.
- **action** (C#) - Optional - Wait-for-event action.
- **callback** (Java) - Optional - Wait-for-event callback.

### Response
#### Success Response
- **Response** ([Response]) - The matched network response object.

### Mock API requests using page.route in JavaScript

Source: https://github.com/microsoft/playwright/blob/v1.64.1/docs/src/mock.md

Intercepts calls to the fruit API pattern and fulfills the request with custom JSON before navigating. Ensures no actual network request reaches the backend API.

```javascript
test("mocks a fruit and doesn't call api", async ({ page }) => {
  // Mock the api call before navigating
  await page.route('*/**/api/v1/fruits', async route => {
    const json = [{ name: 'Strawberry', id: 21 }];
    await route.fulfill({ json });
  });
  // Go to the page
  await page.goto('https://demo.playwright.dev/api-mocking');

  // Assert that the Strawberry fruit is visible
  await expect(page.getByText('Strawberry')).toBeVisible();
});
```
