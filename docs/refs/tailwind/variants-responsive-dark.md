### Combining multiple conditional variants

Source: https://github.com/tailwindlabs/tailwindcss.com/blob/main/src/docs/styling-with-utility-classes.mdx

Stack variants like dark mode, responsive breakpoints, data attributes, and pseudo-classes directly on a single utility class. The paired CSS demonstrates the generated media queries and combined selector logic.

```html
<!-- [!code filename:HTML] -->
<!-- [!code classes:dark:lg:data-current:hover:bg-indigo-600] -->
<button class="dark:lg:data-current:hover:bg-indigo-600 ...">
  <!-- ... -->
</button>
```

```css
/* [!code filename:Simplified CSS] */
@media (prefers-color-scheme: dark) and (width >= 64rem) {
  button[data-current]:hover {
    background-color: var(--color-indigo-600);
  }
}
```

### Configure dark mode with a class selector

Source: https://github.com/tailwindlabs/tailwindcss.com/blob/main/src/docs/dark-mode.mdx

Override the `dark` variant in `app.css` using `@custom-variant` to apply dark styles when a `.dark` class is present on an ancestor element. In HTML, apply the `dark` class to the `html` root tag.

```css
/* [!code filename:app.css] */
@import "tailwindcss";

/* [!code highlight:2] */
@custom-variant dark (&:where(.dark, .dark *));
```

```html
<!-- [!code filename:HTML] -->
<!-- [!code word:dark\:bg-black] -->
<!-- [!code word:dark] -->
<html class="dark">
  <body>
    <div class="bg-white dark:bg-black">
      <!-- ... -->
    </div>
  </body>
</html>
```

### Define custom breakpoint variable and variant modifier

Source: https://github.com/tailwindlabs/tailwindcss.com/blob/main/src/docs/theme.mdx

Defines a custom responsive breakpoint theme variable `--breakpoint-3xl` to create a `3xl:*` variant modifier in HTML.

```css
/* [!code filename:app.css] */
@import "tailwindcss";

@theme {
  /* [!code highlight:2] */
  --breakpoint-3xl: 120rem;
}
```

```html
<!-- [!code filename:HTML] -->
<!-- [!code word:3xl\:grid-cols-6] -->
<div class="3xl:grid-cols-6 grid grid-cols-2 md:grid-cols-4">
  <!-- ... -->
</div>
```
