### Add Toaster and trigger toast in React

Source: https://github.com/emilkowalski/sonner/blob/v2.0.8/README.md

Place <Toaster /> in your app to render toasts, then call toast() from anywhere. The example shows a button that triggers a toast when clicked.

```jsx
import { Toaster, toast } from 'sonner';

// ...

function App() {
  return (
    <div>
      <Toaster />
      <button onClick={() => toast('My first toast')}>Give me a toast</button>
    </div>
  );
}
```

### Usage

Source: https://github.com/emilkowalski/sonner/blob/v2.0.8/README.md

Add `<Toaster />` to your app, it will be the place where all your toasts will be rendered.
After that you can use `toast()` from anywhere in your app.
