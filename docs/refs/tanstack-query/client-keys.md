### Query Retries > Global Configuration

Source: https://github.com/tanstack/query/blob/v5.90.3/docs/framework/angular/guides/query-retries.md

You can configure retry behavior globally for all queries by setting default options on the QueryClient. The `retryDelay` option accepts a function that receives the attempt index and returns the delay in milliseconds before the next retry. A common pattern is exponential backoff, where the delay increases with each retry attempt. For example, `Math.min(1000 * 2 ** attemptIndex, 30000)` creates an exponential backoff strategy with a maximum delay of 30 seconds, doubling the wait time after each failed attempt.

### Set Global Retry Delay in QueryClient

Source: https://github.com/tanstack/query/blob/v5.90.3/docs/framework/react/guides/query-retries.md

Configures a global exponential back-off strategy for all queries within the QueryClient. The delay starts at 1000ms and doubles with each attempt, capped at a maximum of 30 seconds.

```tsx
// Configure for all queries
import {
  QueryCache,
  QueryClient,
  QueryClientProvider,
} from '@tanstack/react-query'

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      retryDelay: (attemptIndex) => Math.min(1000 * 2 ** attemptIndex, 30000),
    },
  },
})

function App() {
  return <QueryClientProvider client={queryClient}>...</QueryClientProvider>
}
```

### Configure Global Retry Delay with Exponential Backoff

Source: https://github.com/tanstack/query/blob/v5.90.3/docs/framework/angular/guides/query-retries.md

Set default retry behavior for all queries using QueryClient configuration with exponential backoff strategy. The retryDelay function calculates increasing delays between retries, capped at 30 seconds, providing efficient retry timing across the application.

```typescript
import {
  QueryCache,
  QueryClient,
  QueryClientProvider,
} from '@tanstack/angular-query-experimental'

const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      retryDelay: (attemptIndex) => Math.min(1000 * 2 ** attemptIndex, 30000),
    },
  },
})

bootstrapApplication(AppComponent, {
  providers: [provideTanStackQuery(queryClient)],
})
```

### Query Retries

Source: https://github.com/tanstack/query/blob/v5.90.3/docs/framework/react/guides/query-retries.md

When a `useQuery` query fails (the query function throws an error), TanStack Query will automatically retry the query if that query's request has not reached the max number of consecutive retries (defaults to `3`) or a function is provided to determine if a retry is allowed. You can configure retries both on a global level and an individual query level. Setting `retry = false` will disable retries, while setting `retry = 6` will retry failing requests 6 times before showing the final error thrown by the function. On the server, retries default to `0` to make server rendering as fast as possible.

### Disable Query Retries in QueryClient Configuration

Source: https://github.com/tanstack/query/blob/v5.90.3/docs/framework/react/guides/testing.md

Configure QueryClient with default options to disable retries for all queries in tests. This prevents test timeouts when testing error scenarios. Explicit retry settings on individual queries will override these defaults.

```typescript
const queryClient = new QueryClient({
  defaultOptions: {
    queries: {
      // ✅ turns retries off
      retry: false,
    },
  },
})
const wrapper = ({ children }) => (
  <QueryClientProvider client={queryClient}>{children}</QueryClientProvider>
)
```
