### Custom Register with Controller and useWatch

Source: https://react-hook-form.com/docs/usefieldarray

Register inputs at Controller without an actual input, making useFieldArray flexible for complex data structures. Uses useWatch to conditionally render the input based on a checkbox value.

```javascript
import { useForm, useFieldArray, Controller, useWatch } from "react-hook-form"

const ConditionalInput = ({ control, index, field }) => {
  const value = useWatch({
    name: "test",
    control,
  })

  return (
    <Controller
      control={control}
      name={`test.${index}.firstName`}
      render={({ field }) =>
        value?.[index]?.checkbox === "on" ? <input {...field} /> : null
      }
    />
  )
}

function App() {
  const { control, register } = useForm()
  const { fields, append, prepend } = useFieldArray({
    control,
    name: "test",
  })

  return (
    <form>
      {fields.map((field, index) => (
        <ConditionalInput key={field.id} {...{ control, index, field }} />
      ))}
    </form>
  )
}
```

### useFieldArray

Source: https://react-hook-form.com/docs/usefieldarray/fieldarray

The useFieldArray hook provides methods and properties for managing dynamic fields in a form. It returns an object containing fields and mutation methods like append, prepend, insert, remove, swap, move, update, and replace.

```APIDOC
## useFieldArray

### Description
Manages dynamic fields in a React Hook Form. Returns an object with `fields` and methods to mutate the field array.

### Props

| Name | Type | Required | Description |
|------|------|----------|-------------|
| `render` | `Function` | ✓ | Render prop function that receives the same object `useFieldArray` returns (`fields`, `append`, `prepend`, `insert`, `remove`, `swap`, `move`, `update`, `replace`) and returns a React element. |
| `name` | `string` | ✓ | Name of the field array. **Note:** Dynamic names are not supported. |
| `control` | `Object` | | [`control`](https://react-hook-form.com/docs/useform/control) object provided by `useForm`. It's optional if you are using `FormProvider`. |
| `shouldUnregister` | `boolean` | | Whether Field Array will be unregistered after unmount. |
| `disabled` | `boolean` | | Disables the entire field array. When `true`, `fields` remains populated but every entry's `disabled` property is set to `true`, all mutation methods (`append`, `prepend`, `insert`, `remove`, `swap`, `move`, `update`, `replace`) become no-ops, and the array's internal subscriptions are not set up. Useful for conditionally enabling a field array in discriminated union form shapes. |
| `keyName` | `string = "id"` | | Name of the attribute with autogenerated identifier to use as the `key` prop. This prop is no longer required and is removed in v8, where rows always use `key` (see [v8 migration notes](https://react-hook-form.com/migrate-v7-to-v8#useFieldArray)). |
| `rules` | `Object` | | The same validation `rules` API as for [`register`](https://react-hook-form.com/docs/useform/register), which includes: `required`, `minLength`, `maxLength`, `validate`. In case of validation error, the `root` property is appended to `formState.errors?.<name>?.root` (e.g. `formState.errors?.test?.root` for a field array named `test`), of type [`FieldError`](https://react-hook-form.com/ts#FieldError). **Important:** This is only applicable to **built-in** validation. |
```

### useFieldArray basic usage with control and name

Source: https://react-hook-form.com/docs/usefieldarray

Shows the basic useFieldArray hook usage with control from useForm and a unique name. The example maps over fields to render inputs, using field.id as the key. The control prop is optional if using FormProvider.

```javascript
function FieldArray() {
  const { control, register } = useForm()
  const { fields, append, prepend, remove, swap, move, insert } = useFieldArray(
    {
      control, // control props comes from useForm (optional: if you are using FormProvider)
      name: "test", // unique name for your Field Array
    }
  )

  return (
    <>
      {fields.map((field, index) => (
        <input
          key={field.id} // important to include key with field's id
          {...register(`test.${index}.value`)}
        />
      ))}
    </>
  )
}
```

### useFieldArray

Source: https://react-hook-form.com/docs/usefieldarray

Hook to manage an array of fields in React Hook Form. It provides methods to append, prepend, insert, remove, swap, move, and update fields, and returns the current fields array.

```APIDOC
## useFieldArray

### Description
Hook to manage an array of fields in React Hook Form. It provides methods to append, prepend, insert, remove, swap, move, and update fields, and returns the current fields array.

### Parameters
#### Props
- **name** (string) - Required - Name of the field array. Dynamic names are not supported.
- **control** (Object) - Optional - `control` object provided by `useForm`. Optional if using `FormProvider`.
- **shouldUnregister** (boolean) - Optional - Whether the Field Array will be unregistered after unmounting.
- **disabled** (boolean) - Optional - (since v7.79.0) Disables the entire field array. When `true`, `fields` remains populated but every entry's `disabled` property is set to `true`, all mutation methods become no-ops, and internal subscriptions are not set up.
- **keyName** (string = "id") - Optional - Name of the attribute with autogenerated identifier to use as the `key` prop. If field objects already contain an `id` property, it will be overwritten unless a custom `keyName` is set. Removed in v8.
- **rules** (Object) - Optional - (since v7.34.0) Same validation `rules` API as for `register`, including `required`, `minLength`, `maxLength`, `validate`. On validation error, `root` property is appended to `formState.errors?.<name>?.root`.

### Request Example
```javascript
function FieldArray() {
  const { control, register } = useForm()
  const { fields, append, prepend, remove, swap, move, insert } = useFieldArray(
    {
      control, // control props comes from useForm (optional: if you are using FormProvider)
      name: "test", // unique name for your Field Array
    }
  )

  return (
    <>
      {fields.map((field, index) => (
        <input
          key={field.id} // important to include key with field's id
          {...register(`test.${index}.value`)}
        />
      ))}
    </>
  )
}
```
