### Create TypeScript Store with Persist Middleware

Source: https://github.com/pmndrs/zustand/blob/v5.0.12/docs/reference/integrations/persisting-store-data.md

Demonstrates basic TypeScript usage with Zustand's persist middleware to automatically save state to sessionStorage. Requires generic type parameter on create function and defines custom storage configuration with partialize option to selectively persist state properties.

```typescript
import { create } from 'zustand'
import { persist, createJSONStorage } from 'zustand/middleware'

interface MyState {
  bears: number
  addABear: () => void
}

export const useBearStore = create<MyState>()(
  persist(
    (set, get) => ({
      bears: 0,
      addABear: () => set({ bears: get().bears + 1 }),
    }),
    {
      name: 'food-storage',
      storage: createJSONStorage(() => sessionStorage),
      partialize: (state) => ({ bears: state.bears }),
    },
  ),
)
```

### Persist Store State with persist Middleware

Source: https://github.com/pmndrs/zustand/blob/v5.0.12/docs/learn/guides/beginner-typescript.md

Configures the store to persist its state in a storage engine like localStorage. This ensures that the application state survives page refreshes.

```ts
import { create } from 'zustand'
import { persist } from 'zustand/middleware'

interface BearState {
  bears: number
  increase: () => void
}

export const useBearStore = create<BearState>()(
  persist(
    (set) => ({
      bears: 0,
      increase: () => set((s) => ({ bears: s.bears + 1 })),
    }),
    { name: 'bear-storage' }, // localStorage key
  ),
)
```

### Optimize Multiple Selectors with useShallow in Zustand

Source: https://github.com/pmndrs/zustand/blob/v5.0.12/docs/learn/guides/beginner-typescript.md

Demonstrates how to select multiple properties from a store using an object. It utilizes the useShallow hook to prevent unnecessary re-renders when the selected values remain shallowly equal.

```tsx
import { create } from 'zustand'
import { useShallow } from 'zustand/react/shallow'

// Bear store with explicit types
interface BearState {
  bears: number
  food: number
}

const useBearStore = create<BearState>()(() => ({
  bears: 2,
  food: 10,
}))

// In components, you can use both stores safely
function MultipleSelectors() {
  const { bears, food } = useBearStore(
    useShallow((state) => ({ bears: state.bears, food: state.food })),
  )

  return (
    <div>
      We have {food} units of food for {bears} bears
    </div>
  )
}
```

### Persisting Zustand Store Data with `persist` Middleware

Source: https://github.com/pmndrs/zustand/blob/v5.0.12/README.md

Demonstrates how to use Zustand's `persist` middleware to automatically save and restore store data to a chosen storage mechanism, such as `sessionStorage`. The example configures the persistence with a unique name and specifies `createJSONStorage` for handling serialization.

```jsx
import { create } from 'zustand'
import { persist, createJSONStorage } from 'zustand/middleware'

const useFishStore = create(
  persist(
    (set, get) => ({
      fishes: 0,
      addAFish: () => set({ fishes: get().fishes + 1 }),
    }),
    {
      name: 'food-storage', // name of the item in the storage (must be unique)
      storage: createJSONStorage(() => sessionStorage), // (optional) by default, 'localStorage' is used
    },
  ),
)
```
