### Compose Toolbar with DropdownMenu using asChild

Source: https://www.radix-ui.com/primitives/docs/components/toolbar

Use the asChild prop to compose a DropdownMenu trigger within a Toolbar. The example imports Toolbar and DropdownMenu from radix-ui and nests a DropdownMenu.Root inside Toolbar.Root, with Toolbar.Button asChild wrapping DropdownMenu.Trigger.

```jsx
import { Toolbar, DropdownMenu } from "radix-ui";

export default () => (
  <Toolbar.Root>
    <Toolbar.Button>Action 1</Toolbar.Button>

    <Toolbar.Separator />

    <DropdownMenu.Root>
      <Toolbar.Button asChild>
        <DropdownMenu.Trigger>Trigger</DropdownMenu.Trigger>
      </Toolbar.Button>

      <DropdownMenu.Content>…</DropdownMenu.Content>
    </DropdownMenu.Root>
  </Toolbar.Root>
);
```

### Composing multiple primitives with asChild (Tooltip and Dialog)

Source: https://www.radix-ui.com/primitives/docs/guides/composition

Nest asChild to combine Tooltip.Trigger and Dialog.Trigger with a custom button. The custom component must spread props and forward refs.

```jsx
import * as React from "react";

import { Dialog, Tooltip } from "radix-ui";

const MyButton = React.forwardRef((props, forwardedRef) => (
  <button {...props} ref={forwardedRef} />
));

export default () => {
  return (
    <Dialog.Root>
      <Tooltip.Root>
        <Tooltip.Trigger asChild>
          <Dialog.Trigger asChild>
            <MyButton>Open dialog</MyButton>
          </Dialog.Trigger>
        </Tooltip.Trigger>

        <Tooltip.Portal>…</Tooltip.Portal>
      </Tooltip.Root>

      <Dialog.Portal>...</Dialog.Portal>
    </Dialog.Root>
  );
};
```

### Composition > Composing multiple primitives

Source: https://www.radix-ui.com/primitives/docs/guides/composition

`asChild` can be used as deeply as you need to. This means it is a great way to compose multiple primitive's behavior together. Here is an example of how you can compose `Tooltip.Trigger` and `Dialog.Trigger` together with your own button:

```jsx
import * as React from "react";

import { Dialog, Tooltip } from "radix-ui";

const MyButton = React.forwardRef((props, forwardedRef) => (
  <button {...props} ref={forwardedRef} />
));

export default () => {
  return (
    <Dialog.Root>
      <Tooltip.Root>
        <Tooltip.Trigger asChild>
          <Dialog.Trigger asChild>
            <MyButton>Open dialog</MyButton>
          </Dialog.Trigger>
        </Tooltip.Trigger>

        <Tooltip.Portal>…</Tooltip.Portal>
      </Tooltip.Root>

      <Dialog.Portal>...</Dialog.Portal>
    </Dialog.Root>
  );
};
```

### Dialog.Trigger

Source: https://www.radix-ui.com/primitives/docs/components/dialog

The button that opens the dialog. It can be styled using the `asChild` prop.

```APIDOC
## Dialog.Trigger

### Description
The button that opens the dialog. It can be styled using the `asChild` prop.

### Props
- `asChild` (boolean) - Optional - Default `false`. When true, the component will render as its child, passing all props and behavior to that child.

### Data Attributes
- `[data-state]` - Values: `"open" | "closed"` - The current open state of the dialog.
```
