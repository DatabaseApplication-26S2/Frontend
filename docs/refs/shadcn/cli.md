### View options for shadcn add command

Source: https://github.com/shadcn-ui/ui/blob/shadcn@4.21.0/apps/v4/content/docs/(root)/cli.mdx

Displays the command usage, arguments, and available options for the `shadcn add` CLI command.

```bash
Usage: shadcn add [options] [components...]

add a component to your project

Arguments:
  components           name, url or local path to component

Options:
  -y, --yes            skip confirmation prompt. (default: false)
  -o, --overwrite      overwrite existing files. (default: false)
  -c, --cwd <cwd>      the working directory. defaults to the current directory.
  -a, --all            add all available components (default: false)
  -p, --path <path>    the path to add the component to.
  -s, --silent         mute output. (default: false)
  --dry-run            preview changes without writing files. (default: false)
  --diff [path]        show diff for a file.
  --view [path]        show file contents.
  -h, --help           display help for command
```

### Configure components.json for JavaScript

Source: https://github.com/shadcn-ui/ui/blob/shadcn@4.21.0/apps/v4/content/docs/(root)/javascript.mdx

Set the tsx flag to false in components.json to opt-out of TypeScript when using the shadcn CLI.

```json
{
  "style": "new-york",
  "rsc": false,
  "tsx": false,
  "tailwind": {
    "config": "",
    "css": "src/app/globals.css",
    "baseColor": "zinc",
    "cssVariables": true
  },
  "iconLibrary": "lucide",
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  }
}
```
